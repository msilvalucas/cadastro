# 📋 Cadastro de Pessoas | 4Asset

Este é um projeto de interface web para **cadastro e gerenciamento de pessoas**, desenvolvido com **HTML5, Bootstrap 5 e CSS personalizado**. O sistema simula funcionalidades como adicionar, editar e excluir registros por meio de modais intuitivos.

---

## 🚀 Funcionalidades

- ✅ Cadastro de novas pessoas via modal
- ✏️ Edição de cadastros existentes
- 🗑️ Exclusão de registros com confirmação
- 📄 Visualização dos dados em uma tabela responsiva
- 📦 Interface amigável com uso do Bootstrap 5
- 🎨 Layout centralizado e responsivo

---

## 🧰 Tecnologias Utilizadas

- HTML5
- CSS3
- [Bootstrap 5](https://getbootstrap.com/docs/5.1/getting-started/introduction/)
- SVGs para ícones
- Modais interativos (sem JS personalizado)
